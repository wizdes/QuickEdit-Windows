Save check · QuickEdit for Windows

A Save now checks the disk before and after its swap.

The two orange shapes changed. Before, a deleted file skipped the first check, and the second check compared only the byte count.

Limit: another program's same-size write within one step of the file time, about 16 ms on NTFS, still goes unseen. When only the time moved, as it does for a file with a hidden data stream, the worker reads the file back and compares its bytes. A new file index does not count as an outside write. No real FAT or exFAT drive was tried.
