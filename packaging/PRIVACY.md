# QuickEdit privacy policy

QuickEdit is a plain-text editor for Windows. It has no network code and contacts no server. It has no account, no analytics and no ads. The developer receives nothing about you or your files.

## What QuickEdit reads and writes

- **Files you open or save.** QuickEdit reads a file when you open it, and writes a file when you save it or export a PDF. These files can hold personal information, because they hold whatever you typed in them. They stay where you put them.
- **Settings, session and autosave.** QuickEdit copies unsaved text to your PC as you work, so that it comes back after a crash or a restart. It keeps that text, its settings and the list of open tabs in its own folder.
  - The app sees this folder as `%LOCALAPPDATA%\QuickEdit`.
  - For the Store version, Windows keeps the folder under `%LOCALAPPDATA%\Packages\<package family name>\LocalCache\Local\QuickEdit`.
  - The autosave copies are plain files. Other programs that run as you, and anyone with an administrator account on the PC, can read them.
  - If you run QuickEdit as administrator, unsaved text goes to the same folder, even if the file itself is one only administrators can read.
- **Recent files.** The list of recent files is in the same folder.

## Windows features that QuickEdit uses

- **Spell check.** QuickEdit uses the spell checker built into Windows. If you add a word, Windows keeps it in your Windows dictionary, which other apps on the PC also use. QuickEdit does not send your text anywhere for this. See Microsoft's privacy statement for how Windows handles its own features.
- **Network shares.** If you open a file on a network share, Windows reads it over the network for you. QuickEdit itself makes no network connection.
- **Open and Save dialogs.** These are part of Windows.

## Removing your data

Uninstalling the Store version deletes QuickEdit's own folder, including autosaved text that you never saved to a file. Save your work first. Your saved files are not touched.

Before you uninstall, you can also delete a word from your Windows dictionary in the Windows settings for spell check.
